# 🧠 QuillMind

> **Write Smarter. Publish Better.**

QuillMind is an AI-powered blogging platform built with the **MERN Stack** that helps writers create, optimize, and publish high-quality content. It combines a Markdown-based editor, AI-assisted writing, SEO analysis, and analytics into a modern blogging experience.

---

## ✨ Features

### 🔐 Authentication

* User Registration & Login
* JWT Authentication
* Password Hashing with bcrypt
* Protected Routes

### ✍️ Blog Management

* Create, Edit & Delete Blogs
* Save Drafts
* Publish Articles
* Blog Search
* Tags & Categories

### 📝 Markdown Editor

* Live Markdown Preview
* Rich Writing Experience
* Auto Save (Planned)

### 🤖 AI Features

* AI Content Suggestions
* AI Blog Title Generation
* AI Paragraph Improvement
* AI Tag Generation
* AI Content Expansion

### 📈 SEO Optimization

* SEO Score
* Meta Title & Description
* Reading Time Estimation
* Slug Generation
* Keyword Analysis

### 📊 Analytics

* Blog Views
* Reading Statistics
* Author Dashboard

### 💎 Planned Features

* User Subscriptions
* Monetization
* Server-Side Rendering (SSR)
* Email Notifications
* Social Sharing

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/meshivamguptaa/QuillMind.git
```

## Backend

```bash
cd backend
npm install
npm run dev
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```
