# QuillMind - Project Overview

## Description

QuillMind is an AI-powered blogging platform built with the MERN stack that enables users to write, edit, optimize, and publish blog posts using AI-assisted tools.

## Objectives

- Build a scalable MERN application
- Implement secure authentication
- Integrate AI-powered writing assistance
- Provide SEO optimization tools
- Track blog analytics
- Deliver a responsive user experience

## Technology Stack

### Frontend

- React
- Vite
- Tailwind CSS v4

### Backend

- Node.js
- Express.js
- MongoDB

### AI

- OpenAI Compatible API

### Version Control

- Git & GitHub
